# 🍽️ Web-Katering (Ojan Catering)

Website profil perusahaan dan portofolio layanan katering modern yang menyediakan berbagai pilihan makanan sehat, lezat, dan praktis. Proyek ini dirancang untuk memberikan pengalaman informatif bagi pelanggan yang ingin melihat profil usaha, galeri menu, ulasan, serta informasi kontak.

## 🚀 Fitur Utama

- **Halaman Beranda (Home):** Menampilkan sambutan, keunggulan layanan, serta statistik pencapaian usaha.
- **Profil Perusahaan (Profile):** Berisi sejarah singkat sejak 2007, komitmen bahan segar, dan ulasan (_Google Reviews_) dari pelanggan.
- **Galeri Menu (Galery):** Menampilkan album foto pilihan menu katering dengan efek visual interaktif (_hover zoom_).
- **Hubungi Kami (Contact Us):** Informasi alamat lengkap, jam operasional, serta akses cepat menuju layanan pemesanan via WhatsApp.
- **Desain Responsif:** Tampilan optimal dan rapi saat diakses melalui perangkat seluler maupun komputer.

## 💻 Teknologi yang Digunakan

- **HTML5 & CSS3** (Struktur & Desain Dasar)
- **Bootstrap 5** (Framework CSS untuk tampilan modern dan responsif)
- **Font Awesome** (Ikon pendukung antarmuka)
- **Google Fonts (Poppins)** (Tipografi teks yang bersih dan elegan)
- **GitHub Pages** (Platform _hosting_ untuk publikasi website)
